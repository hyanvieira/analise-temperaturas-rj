📄 README — Análise de Temperaturas do RJ
🌡️ Análise Histórica das Temperaturas no Rio de Janeiro

Este projeto realiza uma análise exploratória de dados meteorológicos do Rio de Janeiro a partir de um dataset contendo registros de temperatura. Utilizando Python e bibliotecas como Pandas e Matplotlib, o notebook identifica padrões, extremos e tendências históricas.

📚 Tecnologias Utilizadas

Python 3

Pandas — tratamento e análise de dados

Matplotlib — visualização gráfica

Jupyter Notebook — ambiente interativo

📊 O que foi feito
✔️ 1. Carregamento e inspeção dos dados

Leitura do arquivo temperatura-RJ.csv

Conversão da coluna de datas e definição como índice

Verificação de valores nulos e consistência do dataset

✔️ 2. Estatísticas descritivas

Média, mediana, mínimo e máximo das temperaturas

Resumo estatístico geral dos registros

✔️ 3. Visualizações

Boxplot para observar outliers e distribuição

Médias mensais históricas

Médias anuais históricas

✔️ 4. Identificação de extremos

Dia mais frio registrado

Dia mais quente registrado

Ano mais quente da série histórica

Praticar habilidades de:
